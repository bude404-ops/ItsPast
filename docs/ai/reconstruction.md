# Evidence-Backed AI Reconstruction

AI reconstructions in ItsPast are generated interpretations, never historical photographs.

Every reconstruction must disclose:
- AI GENERATED
- Evidence used
- Confidence
- Unknown elements
- Labels: DOCUMENTED, STRONGLY_INFERRED, ESTIMATED, AI_INTERPRETATION

If evidence is insufficient, return `INSUFFICIENT_EVIDENCE` and do not generate a persuasive image.

AI providers must be called server-side. The frontend contains interfaces and mocks only.
